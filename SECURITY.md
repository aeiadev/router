# Security

Only the latest release is supported.
Report a vulnerability privately through GitHub's private vulnerability reporting on this repository. If that is not available, open an issue that says a security report is waiting and leave the details out.
These tools read command text and install files under your Claude Code and Codex homes. The danger guard is a best-effort check of common command forms, not a sandbox.
No response time is promised.

Include the affected version, the steps to reproduce, and the expected impact in a private report.
